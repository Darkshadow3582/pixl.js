# Web UI 重构：从 Vue 2 到 React 的现代化改造

## 概述

将 Pixl.js Web 界面从 Vue 2 + Element UI 迁移到 React + TypeScript + Tailwind CSS + shadcn/ui。在保留全部现有功能的前提下，以现代、简洁的工具型美学重新设计用户体验。

## 技术栈

| 层 | 选择 | 理由 |
|-------|--------|-----------|
| 框架 | React 18 + TypeScript | 用户要求 |
| 构建工具 | Vite | 现代化、快速、ESM 原生 |
| UI 组件库 | shadcn/ui（Radix 原语） | 简洁、可组合、最小化 |
| 样式方案 | Tailwind CSS 4 | 工具类优先、一致性强 |
| 路由 | React Router v6 | SPA 标准方案 |
| 国际化 | react-i18next | 成熟方案，与现有配置平行 |
| BLE 层 | **保持不变** | 原样复用 `pixl.ble.js` 和 `pixl.proto.js` |
| 状态管理 | zustand（连接状态）+ 组件状态（文件缓存） | 轻量且够用 |

## 页面结构

### 布局

- **侧边栏**（左侧固定）：图标 + 文字导航项，窄屏可折叠
- **顶栏**：Pixl.js Logo（左），BLE 连接按钮（中右），语言切换（右）
  - BLE 按钮状态："连接"（默认）、"连接中..."（旋转动画）、"断开连接"（绿色，已连接时）
- **主内容区**：路由渲染区域

### 路由

| 路径 | 页面 | 说明 |
|-------|------|-------------|
| `/` | 仪表盘 | 设备概览 |
| `/files` | 文件管理 | 浏览和管理设备文件 |
| `/settings` | 设置 | 固件更新、语言、关于 |

---

## 页面：仪表盘（`/`）

三卡片布局，响应式网格排列：

1. **设备信息卡**
   - 连接状态指示器（绿点 + "已连接" / 灰点 + "未连接"）
   - 固件版本号
   - BLE MAC 地址

2. **存储概览卡**
   - 每个驱动器：环形图显示已用 vs 总空间
   - 颜色编码：绿色（<60%）、橙色（60-85%）、红色（>85%）
   - 标签：驱动器名称 + "X 已用 / Y 总计"

3. **快捷操作卡**
   - "进入 DFU 模式"按钮（附确认对话框）
   - "刷新"按钮
   - "断开连接"按钮（仅连接时显示）

空状态：未连接时，居中显示提示信息："连接你的 Pixl.js 设备以开始使用"，并引导用户使用顶栏的连接按钮。

## 页面：文件管理（`/files`）

### 工具栏（顶部）
- 上传按钮 → 打开系统文件选择器
- 新建文件夹按钮 → 内联输入文件夹名称
- 删除按钮 → 批量删除选中项（需确认）
- 返回上级按钮 → 导航到父目录
- 刷新按钮 → 重新读取当前目录
- 搜索输入框 → 按名称过滤文件（客户端过滤）
- 视图切换 → 在**网格（图标）**和**列表（表格）**视图间切换

### 文件展示

- **默认：网格视图** — 大图标平铺排列在响应式网格中
  - 文件夹：文件夹图标 + 下方名称
  - 文件：文档图标 + 名称、大小、类型
  - 点击文件夹进入，点击文件下载
  - 悬停时显示复选框

- **备选：列表视图** — 表格列：名称（带图标）、大小、类型、备注
  - 列可排序
  - 行右键菜单：重命名、删除、属性

### 路径导航
- 工具栏下方的面包屑路径，显示当前路径各段
- 点击任意段可跳转返回

### 右键菜单（两种视图通用）
- **重命名**：内联输入新名称
- **删除**：确认对话框后删除
- **属性**：对话框显示文件备注、隐藏/只读标志、Amiibo head/tail ID

### 上传对话框
- 拖拽区域或文件选择器
- 每个文件显示进度条（已写入字节 / 总字节）
- 支持多文件上传
- 关闭对话框时提示："上传进行中，是否取消？"确认

## 页面：设置（`/settings`）

垂直排列的设置分组：

1. **固件**
   - 当前版本显示
   - "进入 DFU 模式"按钮 → 确认 → 跳转到 Web Bluetooth DFU 页面

2. **语言**
   - 下拉选择 8 种语言：简体中文、繁體中文、English、Español、Русский、Deutsch、Svenska、日本語
   - 保存到 Cookie（与当前行为一致）

3. **关于**
   - 项目名称和版本
   - GitHub 链接
   - 开源许可证信息

## BLE 集成

- **保持不变**：`src/lib/pixl.ble.js` 和 `src/lib/pixl.proto.js` 原样保留
- 连接状态通过 zustand 管理：
  ```ts
  interface ConnectionState {
    connected: boolean
    version: string | null
    bleAddress: string | null
    connect: () => Promise<void>
    disconnect: () => void
  }
  ```
- 保留事件派发器模式（共享事件总线）
- 文件操作封装为异步 hooks（如 `useFiles`、`useDriveInfo`）

---

## 国际化策略

- 将现有语言文件（zh_Hans、en_US 等）迁移为 react-i18next JSON 格式
- 保持相同的键结构和翻译内容
- 语言偏好通过 Cookie 持久化（react-cookie）
- 默认：浏览器语言检测 → 回退到 zh_CN

---

## 状态管理

| 状态 | 位置 | 说明 |
|-------|----------|---------|
| BLE 连接 | zustand store | 全局可访问 |
| 当前目录 | 组件状态（`useFiles` hook） | 按路由 |
| 文件列表缓存 | 组件状态（`useFiles` hook） | 断开连接时清除 |
| 选中文件 | 组件状态 | 用于批量操作 |
| 视图模式偏好 | localStorage | 持久化网格/列表选择 |
| 语言偏好 | cookie | 跨会话持久化 |
| UI 主题（侧边栏折叠） | 组件状态 | 仅当前会话 |

---

## 错误处理

- BLE 连接失败：右上角 toast 通知
- 文件操作失败：内联错误 toast，保持文件列表不变
- 上传错误：上传队列中每个文件显示错误状态
- 网络/蓝牙断开：自动检测，重置文件视图，显示 toast
- DFU 进入：确认对话框后跳转

---

## 保持不变的部分

- 所有 BLE 协议逻辑（pixl.ble.js、pixl.proto.js）
- 所有国际化翻译字符串（仅格式变化）
- 所有功能行为（上传、下载、重命名、删除、格式化、元数据编辑）
- 设备通信协议（命令 ID、帧格式、分块传输）
- 部署流程（构建 → 复制到 gh-pages → git subtree push）

---

## 变更的部分

- 框架：Vue 2 → React 18 + TypeScript
- 构建工具：Webpack 2 → Vite
- UI 组件库：Element UI → shadcn/ui + Tailwind CSS
- 布局：单文件巨型组件 → 带侧边栏的多页面路由
- 文件视图：仅表格 → 网格（默认）+ 列表（可切换）
- 视觉风格：传统中式企业风格 → 简洁现代极简风
